BIOPLANT AI Digital Twin & Autopilot

Comprehensive User Manual & Technical Reference Guide (Version 2.0.0)

1. System Architecture & Overview

BIOPLANT AI is an industrial digital twin platform combining first-principles chemical engineering, physics-informed machine learning, and autonomous supervisory control for biomass thermochemical conversion.

Key Achievement (V2.0): Closed-loop autonomous plant operation with a 5-State Finite State Machine (FSM), real-time virtual soft sensors, predictive maintenance, 20-year DCF techno-economics, and ISO 14040/14044 Net Carbon Negative accounting.

2. Quick Start & Execution

Starting the Web Platform

Run the built-in HTTP server to access the live glassmorphism dashboard:

python -m src.web.run_server --port 8000 --open-browser

Access the web application at http://127.0.0.1:8000/.

4. Autonomous Autopilot & Flight Qualification

The Autopilot FSM governs autonomous operations across 5 discrete states:

  • STARTUP_PREHEAT: Automated burner ramp with nitrogen sweep until $T_{bed} \ge 480^\circ\text{C}$.
  • AUTONOMOUS_CRUISE: Nominal steady-state setpoint tracking with thermal self-sufficiency ($TSI \ge 100\%$).
  • DISTURBANCE_ADAPTATION: Feed throttling and burner boost when feed moisture jumps to $22\%$.
  • FAULT_MITIGATION: Self-healing pulse-jet blowback clearing cyclone blockages in 40s.
  • EMERGENCY_SAFE_PARK: NFPA-86 inert cooling sweep upon critical overtemperature.
python -m src.autonomous.run_autopilot --mission

4. Otonom Otopilot ve Görev Yeterliliği

Otopilot FSM, tesisi 5 farklı operasyonel durumda yönetir:

  • STARTUP_PREHEAT: Yatak sıcaklığı $480^\circ\text{C}$ olana kadar azot süpürmeli otomatik brülör ısıtması.
  • AUTONOMOUS_CRUISE: Termal olarak kendi kendine yetebilen nominal seyir ($TSI \ge %100$).
  • DISTURBANCE_ADAPTATION: Hammadde nemi $\%22$'ye fırladığında beslemeyi kısıp brülörü artıran uyarlama.
  • FAULT_MITIGATION: Siklon tıkanmasında 40 saniyede darbeli azot üfleyerek arızayı reaktörü durdurmadan çözen mekanizma.
  • EMERGENCY_SAFE_PARK: Aşırı sıcaklık durumunda NFPA-86 inert soğutma süpürmesi.
python -m src.autonomous.run_autopilot --mission
